# Pyton SPA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a full working single-page application in Vue 3 + TypeScript + Tailwind CSS that presents the NTNU *Eksperter i Team* research project "Pyton med pyton?" across the 7 sections defined in the spec.

**Architecture:** A single scrollable page composed of 7 typed, stateless section components consuming static TypeScript data modules. Navigation uses native `<a href="#id">` anchors with CSS `scroll-behavior: smooth` and `scroll-padding-top` to offset the sticky navbar. Reveal animations via `@vueuse/motion`. All content hard-coded in Norwegian (Bokmål); no backend or data fetching.

**Tech Stack:** Vite · Vue 3 (Composition API, `<script setup lang="ts">`) · TypeScript (strict) · Tailwind CSS · `@vueuse/motion` · Google Fonts (Fraunces + Inter).

**Spec:** `docs/superpowers/specs/2026-04-18-pyton-spa-design.md`

**Verification model:** The spec explicitly defers a unit-test framework to a later pass. Each task uses concrete browser/build verification gates instead of unit tests — running `npm run dev` and inspecting specific DOM output, running `npm run build` to check types/bundling, and visual checks at documented breakpoints.

**Branch:** All work on `docs/pyton-spa-plan` → merge plan → then a separate `feat/pyton-spa-scaffold` branch for the implementation.

Create `src/composables/useReveal.ts` with:

```ts
/**
 * Reveal animation presets for @vueuse/motion.
 *
 * Usage:
 *   <section v-motion="reveal()">            // default fade + y-offset
 *   <div v-motion="reveal(index * 100)">     // staggered children
 */
export function reveal(delay = 0) {
  return {
    initial: { opacity: 0, y: 24 },
    visibleOnce: {
      opacity: 1,
      y: 0,
      transition: {
        duration: 600,
        delay,
        ease: 'easeOut',
      },
    },
  }
}

/** Larger entrance for the hero — triggered on mount, not on scroll. */
export function heroEntrance() {
  return {
    initial: { opacity: 0, y: 64 },
    enter: {
      opacity: 1,
      y: 0,
      transition: {
        duration: 800,
        delay: 100,
        ease: 'easeOut',
      },
    },
  }
}
```
